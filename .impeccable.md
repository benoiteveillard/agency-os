# Design context

Agency OS helps agency project leads assess delivery risk across Linear, GitHub and Slack, inspect evidence and explicitly approve or reject a proposed action. The interface should be calm, precise and trustworthy. The customer asked for a substantial UI improvement after successful Railway deployment.

Use a light workspace with restrained forest-green accents, generous reading space, clear type hierarchy and minimal containers. Lead completed investigations with the verdict, then blockers and their evidence. On desktop, keep uncertainties and the proposed action in an adjacent column; on small screens, preserve a single reading order. Keep technical run details available on demand.

Source state must reflect actual SSE events. Do not fabricate connectivity, completion, percentages, metrics or execution success. External content is plain text. Approval behavior stays governed by the existing API and server policy. Visual testing uses isolated local fixtures and never invokes paid integrations.
